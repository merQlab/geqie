# geqie-qml

QML integration extensions for [geqie](../geqie/README.md).

## Installation

Pre-release from PyPI:

```bash
pip install --pre geqie-qml
```

From source:

```bash
pip install .
```

## Examples

See [`examples/geqie_qml_precompute.ipynb`](../examples/geqie_qml_precompute.ipynb) for the QML precomputation pipeline.
